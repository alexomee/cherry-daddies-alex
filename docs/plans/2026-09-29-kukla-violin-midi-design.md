# Кукла колдуна — черновая MIDI-транскрипция скрипок

## Согласовано

Alex подтвердил разбор `strings.wav` в две MIDI-партии: основной/верхний голос и второй/нижний голос в двухголосных местах. Это редактируемая транскрипция, не обещание точной партитуры. Нужны обратное озвучивание и проверка ложных обертоновых нот.

## Вход и результат

- Вход: `music/songs/Король и Шут - Кукла колдуна/strings.wav`, stereo 44100 Hz, 203.940862 s; уже выровнен по темпу.
- Темп 148.6 BPM, 4/4, pitch shift 0 (D minor).
- Render-frame: добавить к исходным секундам `auto-render/timeline.json:offset_sec` (3.057926 s). Нулевая позиция MIDI соответствует нулю файлов auto-render.
- Выход: отдельная `transcription/violin-v1/` в папке песни; двухдорожечный MIDI, по одному MIDI на голос, аудиопревью, таблица нот/спорных мест, README и воспроизводимый скрипт.
- Исходник, mix.json и боевой playback сохраняются.

## Метод

Полифоническое распознавание Basic Pitch (ONNX, локально), затем сверка с гармоническим спектром WAV. Фильтрация коротких/слабых ложных нот; проверка интервалов и октавных дублей; разнесение голосов по высоте и непрерывности фраз. Не придумывать отсутствующий второй голос. Не квантовать жёстко и не переводить вибрато в отдельные MIDI-ноты.

## Проверка

Проверить начало, интервальные места и финал по WAV/спектру и обратному синтезу. Перечитать MIDI: темп, число дорожек, времена, диапазон, отсутствие pitch-bend и зависших/нулевых нот. Сверить render-смещение и сверить спектральное покрытие. Оставить явно обозначенные сомнительные места для слуховой правки в Logic.
