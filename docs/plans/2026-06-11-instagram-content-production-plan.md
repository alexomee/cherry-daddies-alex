# Cherry & Daddies — План продакшена контента (Countdown Engine)

> **Для Claude:** при исполнении вести по задачам сверху вниз, уважая зависимости. Готовый ассет → в `assets/…`, отметка «✅ готов» в `content-calendar.md`. Проверка вместо тестов — «Чек готовности к публикации» в конце каждой задачи.

**Цель:** произвести и подготовить к публикации весь контент 15-дневного обратного отсчёта (11→26 июня) для @cherry_and_daddies по стратегии «Countdown Engine».

**Подход:** сначала я делаю переиспользуемый фундамент (шаблоны/графика через Higgsfield), параллельно группа снимает видео по брифам, затем посуточная сборка постов (ассет + двуязычная подпись + хэштеги) и публикация по календарю.

**Стек:** Higgsfield CLI (`nano_banana_2`), ffmpeg/ImageMagick (нарезка/форматы), Instagram (Reels/Stories/карусели). Спецификация: `docs/plans/2026-06-11-instagram-content-strategy-design.md`, расписание: `content-calendar.md`.

**Обозначения ответственности:** 🤖 = генерю я (Higgsfield/AI) · 🎥 = снимает группа · 📝 = подпись/текст.

**Файлы:**
- Создать: `assets/stories/templates/story_template_grunge_9x16.png`

**Шаги:**
1. Загрузить исходник афиши в Higgsfield (`higgsfield upload create …`).
2. `nano_banana_2`, `--aspect_ratio 9:16`, промпт: пустой гранж-фон «вишни» (циан/розовый, рваная бумага) с местом под заголовок сверху и плашку снизу, БЕЗ людей и БЕЗ текста (чистый шаблон).

**Чек готовности:** 1080×1920 (или 9:16), стиль совпадает с брендом, есть пустые зоны под текст, нет артефактов текста.
**«Коммит»:** сохранить в `assets/stories/templates/`, отметить в календаре.
