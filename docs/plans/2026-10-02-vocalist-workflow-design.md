# Самостоятельная работа вокалистки с lyrics

Согласовано с Alex 2026-10-02.

## Репозитории и команды пользователя

- `alexomee/cherry-daddies-alex` — **весь** текущий рабочий репозиторий группы.
- `basbit/cherry-daddies-2000` — сценический MainStage-риг клавишника.
- «Сохрани» = проверка, commit и успешный push в основной репозиторий.
- «Сохрани и отправь клавишнику» = дополнительно доставка выбранной песни,
  проверка, commit и успешный push в риг.
- Push в риг не подтверждает Pull на ноутбуке клавишника.

## Пользовательский путь

Агент в ChatGPT Desktop/Codex читает AGENTS.md. Таня (`tkozinets`) указывает
песню/аудио, получает экранное превью, просит исправления и сохранение.
JamZone установлен у неё локально; песню нужно скачать. Не-JamZone песни
транскрибируются автоматически, исходное распознавание сохраняется. Локальный
Whisper — воспроизводимый вариант без API-оплаты; транскрипт из встроенных
средств ChatGPT можно использовать, но доступность такого файлового инструмента
не предполагается. Подписка ChatGPT не включает оплату OpenAI Audio API.

## Проверка и доставка

- Сценические клипы сохраняют существующее оформление make_song_clip.py.
- Таймкоды TSV — секунды финального плейбека, включая отсчёт; offset применяется
  ровно один раз. Для новой/иной аранжировки требуется реальная проверка аудио.
- Превью содержит сценические субтитры и таймкод. Человек проверяет слова,
  повторения, читабельность и синхрон; автоматические проверки проверяют формат,
  диапазон времени, источники, длительность и наличие артефактов.
- Ревью фиксирует хеши источников/клипов/аудио и снимок соответствующей песни
  рига. Изменение после ревью требует пересборки и нового подтверждения.
- Доставка переносит выбранную пару mp4/ass и выбранную строку songs.tsv,
  сохраняя остальные строки. Изменение той же песни в риге после ревью блокирует
  доставку. Изменение другой песни не мешает.
- Commit рига ссылается на уже отправленный исходный commit. Неудачный push
  сообщается как неудачный push, локальный commit сохраняется для повторной отправки.
- Новая песня получает свободный clip/PC; подключение в актуальном MainStage
  проверяется отдельно. Автоматическая публикация новой строки не означает,
  что External Instrument уже настроен.

## Установка и данные

Пути вычисляются относительно репо либо задаются явно/через CHERRY_RIG_REPO.
Установка проверяет Python, uv, ffmpeg, ffprobe, mpv, Git/GitHub и JamZone.
Аудио, модели, локальные настройки и preview-видео вне Git; клонирование полного
репозитория не скачивает игнорируемые медиа. Инструкции объясняют их получение.
Для рига `tkozinets` нужен write-доступ от `basbit`.

## Проверка реализации

Тесты на временных Git-репозиториях с bare remote: сохранение/доставка, гонки,
изменение аудио, stale review, неудачный push и повтор, изоляция соседних песен.
Синтетический короткий клип проверяет реальный ffmpeg/mpv-проход. Русское аудио
проверяет транскриптор отдельно. Никакие тесты не пушат клипы в боевой риг.
