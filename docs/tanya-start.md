# Таня, начни здесь

Ты будешь говорить агенту, какую песню подготовить и что поправить. Агент сам
работает с файлами и сохраняет их на GitHub. Твоя главная задача — посмотреть
видео с текстами и подтвердить, что по нему удобно петь.

**Git заранее устанавливать не нужно.** Ниже ты попросишь агента проверить Mac
и помочь установить всё необходимое. Аккаунт на сайте GitHub у тебя уже есть;
нужные программы на компьютере агент проверит отдельно.

## 1. Прими два приглашения на GitHub

1. Открой [github.com](https://github.com) в браузере и войди в свой аккаунт.
2. Нажми на аватарку справа сверху и убедись, что это **`tkozinets`**.
3. Открой [приглашение в основной проект](https://github.com/alexomee/cherry-daddies-alex/invitations)
   и нажми **Accept invitation / Принять приглашение**.
4. Открой [приглашение в проект клавишника](https://github.com/basbit/cherry-daddies-2000/invitations)
   и тоже нажми **Accept invitation / Принять приглашение**. Basbit уже отправил его.

Приглашения также могут быть в письмах от GitHub или в уведомлениях под значком
колокольчика. Если видно «приглашение уже принято», переходи дальше. Если ссылка
на приватный проект выдаёт 404, сначала проверь аккаунт; если приглашение истекло,
попроси отправителя прислать новое. Агент затем проверит доступ к обоим проектам.

## 2. Открой приложение с агентом

Открой ChatGPT Desktop и войди в свой аккаунт ChatGPT. Выбери режим работы
с локальными файлами/терминалом — **Codex** либо **Work**, если в нём доступны
эти инструменты. Обычный чат с подключённым GitHub сам по себе этого не заменяет.

Если приложение предлагает выбрать рабочую папку, создай или выбери папку
**Music → CherryDaddies** в своей домашней папке. В ней будут оба проекта.

## 3. Попроси агента скачать проекты

Агент сначала подготовит компьютер, затем скачает проекты. Скопируй и отправь
это сообщение целиком:

```text
Я Таня, мой аккаунт GitHub — tkozinets. Я приняла приглашения в два репозитория.
Я не умею работать с Git и терминалом. Помоги настроить всё на этом Mac:
команды выполняй сам, мне давай по одному простому шагу, когда нужно моё действие.

На этом Mac может не быть Git, Homebrew и GitHub CLI. Сначала проверь их наличие.
Если Git отсутствует, помоги установить Apple Command Line Tools:
проверь xcode-select -p и при необходимости вызови xcode-select --install.
Объясни, что нажать в системном окне, и дождись завершения установки.
Затем убедись, что git --version работает.

Если Homebrew отсутствует, помоги установить его по официальной инструкции
https://brew.sh. Установи GitHub CLI (gh), если его нет. Сам выполняй команды;
меня проси только о действиях в окне установки или входа.

Помоги войти в GitHub через браузер. Проверь, что вход выполнен как tkozinets
и есть право записи в оба репозитория. Используй HTTPS, чтобы мне не пришлось
настраивать SSH-ключи. Не начинай клонирование, пока Git и авторизация не готовы.

Клонируй рядом в ~/Music/CherryDaddies:
https://github.com/alexomee/cherry-daddies-alex.git
https://github.com/basbit/cherry-daddies-2000.git

Если папки уже существуют, сначала проверь, что в них, и используй подходящие
клоны вместо повторного скачивания. Проверь имя/email для моих коммитов;
если email нужен — спроси меня.

После скачивания прочитай в cherry-daddies-alex файл AGENTS.md и репозиторный
скилл .agents/skills/tanya-texts/SKILL.md. Используй его для дальнейшей настройки.
Сообщи, какую папку открыть в приложении, чтобы дальше работать с этим скиллом.
```

Если macOS откроет окно **Command Line Tools**, нажми **Install / Установить**
и дождись окончания. Полный Xcode скачивать не требуется — агенту нужны только
его инструменты командной строки. Остальные шаги установки агент объяснит.

Когда откроется вход в GitHub, войди в браузере как `tkozinets`. Если агент
спросит email для подписи изменений, можно посмотреть свой GitHub email в
**Settings → Emails**. Первая загрузка проекта клавишника может занять время:
в нём есть аудио.

Если агент отвечает, что не может выполнять команды или видеть папки, выбери
в приложении режим Codex/работы с локальным проектом и повтори сообщение там.

## 4. Открой основной проект и попроси скилл провести тебя

После скачивания открой как рабочий проект папку:

**Music → CherryDaddies → cherry-daddies-alex**

Начни новый чат в этом проекте и отправь:

```text
Прочитай репозиторный скилл tanya-texts:
.agents/skills/tanya-texts/SKILL.md

Я впервые это делаю. Проверь настройку обоих репозиториев и нужных программ,
запусти предусмотренную скиллом установку, если она нужна. Затем объясни мне
простыми словами, как мы будем добавлять текст, смотреть видео, исправлять его,
сохранять и отправлять клавишнику. Веди меня по одному шагу.
```

Скилл называется **`tanya-texts`**. В ChatGPT его можно выбрать через `@`; в
Codex — через `$tanya-texts` или меню `/skills`. Фразу `/tanya-texts` агент тоже
знает из инструкций проекта, но отдельное slash-меню зависит от приложения.
Сообщение с полным путём выше работает и без выбора скилла в меню.

## 5. Выбери первую песню

Для JamZone сначала скачай песню внутри приложения, потом напиши агенту:

> Подготовь экранный текст для «Название». Песня скачана в JamZone.

Для русской песни из аудиофайла:

> Подготовь экранный текст для «Название». Аудио лежит в Downloads, файл «…».
> Распознай слова сам, затем покажи мне видео для проверки.

Если для синхронизации не хватает аудио нашей концертной версии, агент скажет,
какой файл попросить у Alex. Тебе не нужно вручную печатать всю песню.

## 6. Посмотри видео и скажи, что исправить

Агент откроет видео с текстами и временем в углу. Посмотри песню целиком:
все ли слова и повторы на месте, вовремя ли появляются строки, удобно ли читать.

Можно отвечать так:

> На 1:24 должно быть «…». Эти две строки объедини. Покажи исправленное видео.

## 7. Подтверди и сохрани

Когда всё верно, напиши одну из двух фраз:

> Я посмотрела это превью, всё правильно. Сохрани.

Это сохранит результат на GitHub основного проекта.

> Я посмотрела это превью, всё правильно. Сохрани и отправь клавишнику.

Это дополнительно отправит готовый экранный текст в проект клавишника. Агент
должен дать ссылки на сохранённые изменения. Клавишнику останется получить
обновления на свой компьютер через **Pull**.

Если агент пишет «на GitHub ещё не отправлено», попроси помочь закончить
отправку — одного локального сохранения недостаточно.
