посылка застряла в Индии, Стив писал в поддержку ROLI). Анбоксинг, панчлайн «Will do rock».

**Продакшн (всё лежит в `/Users/alex/Downloads/edit/`):**

- Пайплайн: skill `video-use` — ElevenLabs Scribe транскрипт (word-level) → EDL по фразам →

  продукт-шот с roli.com, карточка «1 MONTH BEFORE» (`assets/card_1month.mp4`)
- Анимации переиспользуемы: `animations/slot_{title,invite,cert,order,india,ticket,product}/`
- Рецепты: `edl_reel.json` (v3) + `project.md` (полная история итераций, по ней восстановим любую версию)

**Версии:**
- v2 (~50с): билингва-сабы (EN белый / RU жёлтый), поп-апы: тайтл, сертификат («обещали середину мая»),
  заказ €349, карта «застряла в Индии», тикет в поддержку, продукт-шот. **← выбор группы**
- v3 (~49с): по фидбеку Алекса — RU-only сабы, без сертификата/Индии, отдельный экран «1 MONTH BEFORE»,
  без «холодно». Группе зашло меньше.

**Выводы (вкусы группы):**
1. **Больше гэгов = лучше.** Плотность поп-апов/вставок группа предпочла «чистому» минимализму.
2. **Билингва-сабы работают** (RU жёлтый + EN белый) — аудитория смешанная, цветовое разделение читается.
3. **Сторителлинг-вставки ценятся:** сертификат и «застряла в Индии» — ключевые панчи, их удаление обеднило историю.
4. **Собирать фидбек всей группы до итераций** — правки по одному мнению (round 2) ушли в сторону от консенсуса.

**Выводы (процесс):**
1. **Версионировать каждый рендер** (`preview_v2.mp4`, `preview_v3.mp4`…) — перезапись укусила второй раз
   (первый — promo_new.mp4 в хедер-проекте).
2. Транскрипты кэшируются — повторные итерации быстрые, ре-транскрибировать не надо.
3. ElevenLabs ключ настроен в skill `.env`; поп-ап-анимации генерятся параллельными суб-агентами (~3-4 мин на 7 шт).
4. Сабы: дефолтный стиль (FontSize=18) слишком крупный для билингвы — FontSize=13, MarginV=45,
   поддержка переопределения добавлена в render.py (`subtitle_force_style` в EDL).

**Статус:** группа выбрала v2; финальный рендер качества (CRF 18) ещё не делали — спросить, когда постить.
