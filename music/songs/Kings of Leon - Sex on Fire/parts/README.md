# Пользовательский playback

## pb-rhythm-guitar.wav — 2026-11-15

Ритм-гитара для pb-other, собрана из собственных стемов JamZone (Alex): **везде Rhythm Electric Guitar (left), в припевах и бридже только (right)**.
- Сборка: `python3 tools/jamzone/prep_sex_on_fire.py rhythm` (воспроизводимо, wav в git не хранится).
- RIGHT: такты 35–42 (Chorus), 59–74 (Chorus 2), 91–конец (Chorus 3, Bridge, Chorus 4). LEFT: 1–34, 43–58, 75–90. Границы секций JamZone лежат на тактах клика (+3 мс).
- Обе гитары играют без пауз через каждый стык, поэтому переключение = equal-power кроссфейд 20 мс, заканчивается на тактовой линии (атака входящей гитары на сильной доле целая).
- Фрейм **stem** (таймлайн сырых стемов, кладётся на OFF), `derived: true` (источники уже в `all` и стемах сайта → слой только в pb-other).
- Громкость: файл на единичном усилении −26.9 gRMS / −21.6 LUFS. `gain_db +5.0` → в pb-other −21.9 / **−16.6 LUFS**, как гитарные pb в «Ту-лу-ла» (−16.6), «Мало тебя» (−16.7), «Владивосток 2000» (−16.6). По gRMS было бы +7.1 дБ: у JZ-гитары больше верха, метрики расходятся на 2 дБ, выбран LUFS.
- Остальное в pb-other на родном уровне: Arr. Electric Guitar −26.2 LUFS, Synthesizer −27.2 LUFS.
