  - 01:03:08.164 – конец (с такта 99.4).
- Strings без мьютов.
- + фрагмент Moises **Other** 01:03:02.937 – 01:03:08.164 (такт 96.4 → стоп 98.3, хвост затухает к ~01:03:07.7; конец = начало мьюта keys). Список — `OTHER_FRAGMENTS` в скрипте.
