⚠️ ГОЧИ ffmpeg (оба ловил):
1. `-t` ДОЛЖЕН быть INPUT-опцией (ПЕРЕД `-i SRC`) когда входов НЕСКОЛЬКО (overlay бейджа = 2-й -i). Как output-опция при 2 входах он цепляется ко 2-му входу (png), а SRC читается до EOF → клип кодируется до конца 44-мин файла (рунэвей, файлы по 600-880МБ, адски медленно). При одном входе output-`-t` ок.
2. Бейдж-оверлей: НЕ использовать `fade=...:alpha=1` после scale — теряется альфа, бейдж становится прозрачным/невидимым. Использовать `format=rgba` + статичный overlay.
3. Реакшн-кат = цифровой панч из того же 1080p портрет-кадра. Умеренный кроп НЕ изолирует сгруппированную банду (выглядит как wide). Нужен ~2.5× (crop ~430×764) чтобы изолировать человека — чуть мягко, но читается. Кропы 2562: roma(370,498,430,764) drum(690,488,430,764) cat(95,1051,320,569).
4. preset veryfast для черновиков (medium на 10-bit HEVC 60fps = очень медленно).
