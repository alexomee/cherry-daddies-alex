# Tanya (Tatiana)

Ведущий вокал банды. Поёт лид во ВСЕХ песнях сетлиста.

## Живые партии

Источник — ключ `players.tanya` в `music/songs/*/mix.json`. В каждой песне назначен лид-вокальный стем (`NN_Lead_Vocal` в JamZone, `vocals` в Moises). Вокал убирается из practice-миксов; в плейбек/превью тоже не идёт (поёт вживую).

Несколько вокальных стемов в одной песне:
- Alexandra Stan — Mr. Saxobeat: `13_Lead_Vocal_Alexandra_Stan_(ad_lib)`, `14_Lead_Vocal_Alexandra_Stan`, `15_Lead_Vocal_♂`.
- t.A.T.u. — Я сошла с ума: `14_Lead_Vocal_Julia`, `15_Lead_Vocal_Lena`.

## Рабочие факты

- Ревьюер текстов: правки лирики сверяются с Tanya (напр. по-строчный тайминг аутро «Я устал» ожидал её ревью).
- Для вокалистки готовится буклет с текстами (структура + слова, без аккордов) из JamZone — по сетлисту.
