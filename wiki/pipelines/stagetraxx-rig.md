Раскладка выходов не меняется: **click / cues / pb-other / pb-bass**. Отдельного выхода под клавиши нет — партии клавишника идут слоем в `pb-other` (`layers`, см. [jamzone-render](jamzone-render.md)), баланс клавиш запекается в рендере.

Статус: **основной плейбек группы** (2026-11-16). Библиотека собрана генератором; вживую (звук по 4 выходам + MIDI в launcher) ещё не проверено. «Синк в риг» = `stagetraxx_sync.py --apply` (правило в `CLAUDE.md`).

## Генератор — `tools/stagetraxx_sync.py`

Аналог `sync_to_mainstage.sh`, но пишет библиотеку целиком (песни, треки, плейлисты, MIDI):

```bash
tools/stagetraxx_sync.py                    # dry-run, весь сетлист
tools/stagetraxx_sync.py --apply --quit     # записать (закрывает Stage Traxx)
tools/stagetraxx_sync.py --apply "S&M"      # только песни по подстроке (плейлисты не трогает)
tools/stagetraxx_sync.py --set "Music Hall" # только сеты по подстроке
```

- **Источник:** сеты и порядок — `web/songs.json`; стемы — `<song>/auto-render/{click,cues,pb-other,pb-bass}.wav`; номер клипа — `tools/lyric-launcher/songs.tsv`.
- **Разводка (с 2026-11-17):** у каждого трека своя шина, панорама по центру: шина 1 Click, 2 Cues, 3 PB Other, 4 PB Bass (так их и называет Stage Traxx). На какой выход идёт шина, Stage Traxx хранит **отдельно для каждой карты** (prefs `audio_busDeviceSettings`: шина → `{uid, leftChannelIndex, stereo}` по каждому устройству). Песни от карты не зависят: подключил карту, выбрал её в Settings → Audio output device (это меняет и системный выход macOS), и разводка подтянулась сама.
  - **Rubix24 (репа):** шины 1–4 → моновыходы 1–4, четыре раздельных сигнала в пульт. Голосовой тест по выходам 1–4 сыгран 2026-11-18; на пульте подтвердить соло каждой шины.
  - **ГРАБЛЯ: ID карты зависит от USB-порта.** В UID зашит location ID порта: `AppleUSBAudioEngine:Roland:Rubix24:100000:1,2` и `…:1100000:1,2` — один и тот же Rubix в разных портах. Для незнакомого UID у Stage Traxx разводки нет, а выход по умолчанию может остаться на динамиках MacBook. Так было 2026-11-18: карту воткнули в другой порт.
  - **Закрыто на все порты (2026-11-18):** `tools/stagetraxx_ports.py --apply --quit --launch` прописал раскладку Rubix на 24 пути: 3 порта Mac (`usb-drd0/1/2-port-hs`, location `0x00100000`/`0x01100000`/`0x02100000`) напрямую и через хаб, гнёзда 1–7 (`0xNN1P0000`; текущий хаб — USB 2.0 на 4 гнезда). Вложенные хабы не покрыты. Без флагов скрипт = **проверка после подключения**: берёт настоящий UID из CoreAudio, говорит «routed / NOT ROUTED» и выбран ли Rubix24 выходом по умолчанию (это остаётся ручным: Stage Traxx Settings → Audio output device). Бэкап prefs рядом, `*.bak-ports-*`. FLOW 8 и POD Go не затронуты: в их UID серийник, не порт. У GM-800 UID тоже прыгает (`…:00100000`, `01100000`, `02110000`, `00130000`), но он у нас не аудиовыход.
  - **FLOW 8 (дом), с 2026-11-17:** у FLOW 8 только две стереопары, и каждая берёт ЛИБО аналог, ЛИБО USB (Setup → Configure Inputs: 5/6 = линия или STEREO USB 1/2, 7/8 = линия или STEREO USB 3/4; отдельного USB-канала нет, BT — только Bluetooth). Поэтому весь плейбек (4 шины) → USB 3/4 → канал 7/8 на USB, баланс клик/cues/pb — в микшере Stage Traxx; 5/6 = аналог, гитара (POD Go) стерео. Синт (GM-800) — в моно-каналы 3+4 (комбо, джек; панорама L/R) или 1+2 (только XLR). Раньше было: шина 1 → USB 1/2, шины 2–4 → USB 3/4.
  - Раньше было две шины с жёсткой панорамой (Click L / Cues R): дома это разносило звук по разным ушам. Флаг `monoToStereo` в разводке устройства (без подписи в интерфейсе) на моно не влияет, проверено.
  - Системные звуки macOS отправить на динамики MacBook, иначе они уйдут в карту.
- **Моно-даунмикс:** стемы на входе сводятся в моно (`ffmpeg -ac 1`). `pb-other`/`pb-bass` — настоящее стерео, жёсткая панорама стерео-файла выкинула бы одну сторону.
- **`pb-drums`, `pb-other-keys`, `all`** в Stage Traxx не идут (выходов четыре).
- **Табы под заметкой (2026-11-20):** строки ключа `"tab"` из `music/songs/<песня>/parts/*.notes.json` синк дописывает в текст песни после заметки с доски (`song_tabs`). Источник — файл партии, не доска. Табулатура рассчитана на моноширинный шрифт: `lyrics_fixedWidthFont = 1` в настройках Stage Traxx (включено 2026-11-20, действует на текст всех песен). [gm-800-parts](gm-800-parts.md).
- **Служебные песни:** `SERVICE_SONGS` в `tools/stagetraxx_sync.py` — песни вне сетов и сайта, которые синк всё равно держит в библиотеке (плейлист `CD · служебное`). Сейчас одна: «Калибровка уровней» (`music/songs/_Калибровка/`, собирает `tools/calibration_track.py`, см. [level-anchors](level-anchors.md)).
- **`"resend": true`** в mix.json песни — писать каждое переключение POD Go / GM-800, даже на уже активную программу. Для служебных песен из регионов, между которыми прыгают. В обычных песнях повтор программы выбрасывается.
- **Владение:** свои песни скрипт метит `song.notes = cd-sync:<папка>` и обновляет на месте; чужие (ручные) не трогает. Июньский импорт (плейлист «Cherry Daddies», 12 песен) удалён 2026-11-16. Свои плейлисты — `CD · <сет>`.
- **Безопасность:** dry-run по умолчанию; перед записью бэкап базы в `~/.cache/cherry-daddies/stagetraxx-backups/`; Stage Traxx должен быть закрыт.

## Регионы (навигация по песне)

`stagetraxx_sync.py` строит регионы Stage Traxx (таблица `region`) из cue в mix.json. На каждый cue — один регион с именем `<такт> · <текст cue>`, например `17 · alex in`. Регион начинается с `snap_sec` (за такт до первого слова подсказки), так что после прыжка звучит вся подсказка, а за ней секция. Регионы идут без зазоров до конца песни. Время до первого региона становится регионом `count-in`. Режим воспроизведения 0 = «next», обычный (порядок next/loop/loopOnce/stop/skip сверен по бинарнику). Цвет зависит от типа секции по тексту cue: `stop` (последнее слово) — красный, `solo`/`соло` — жёлтый, `chorus`/`припев` — зелёный, `verse`/`куплет` — синий, остальное (all in, bridge, end, count-in…) — серый. Индексы палитры Stage Traxx: red 2, yellow 4, green 5, teal 6, blue 7, gray 10. Порядок взят из бинарника (highlight, primary, red, orange, yellow, green, teal, blue, purple, pink, gray, black, white, clear), 6 и 10 подтверждены на экране.

В Stage Traxx двойной тап по региону перематывает на его начало. Есть команды «Jump to Next Region» и «Select Next Region». Регионы засинканных песен принадлежат синку: созданные вручную при синке заменяются. С 2026-11-17 регионы стоят во всех 62 песнях библиотеки: 679 регионов, из них 98 stop, 43 solo, 53 chorus, 80 verse, остальные серые.

## MIDI → lyric-launcher

В Stage Traxx 4 исходящий per-song MIDI есть только тегами в поле lyrics (поле «MIDI Trigger» = входящее). Генератор пишет:

```
[midi: PC<clip>@1]      загрузка песни → launcher армит клип NN
[midi@play: START]      play → клип катится с 0
[midi@stop: STOP]       stop → стоп-кадр
```

**BOSS GM-800** получает теги на канале 2 из ключа `"gm800"` в mix.json песни: стартовая сцена плюс смены сцен по таймкоду `[midi@MM:SS.mmm: PC<сцена−1>@2]`. Проверено вживую 2026-11-17, точность ±3 мс. Подробности: [gm-800.md](gm-800.md).

Stage Traxx шлёт во все MIDI-порты, виртуальный `LyricLauncher` получает их без настройки (launcher запускать первым). `wire_concert.py` и `.concert` для этого рига не нужны. Свет/видео — теми же тегами, включая таймкод `[midi@01:34.50: …]`.

Ограничения: play с середины песни тоже шлёт START → текст стартует с 0 (launcher не знает позицию). У песен без клипа (Eva 2.0, Ты меня не ищи, Попрошу тебя, Владивосток 2000, Sex on Fire) PC нет — только START/STOP.

## Очередь и клавиши (Stage Traxx 4.0.15, 2026-11-17)

- **Automatic Queue Handling** (Settings → Audio → Playback Settings → Queue) должен быть включён (`playback_autoQueueHandling = 1`). Если выключен, тап по песне её не загружает, а двойной тап только ставит в очередь («Added to queue»).
- **Назначения клавиш/MIDI** хранятся не в базе, а в настройках: `~/Library/Containers/de.dikant.StageTraxx4/Data/Library/Preferences/de.dikant.StageTraxx4.plist`, ключ `remote_triggerMappings` = JSON (Data): `[{"isEnabled":true,"action":"startStop","id":"<UUID>","trigger":{"keyboard":{"key":44}}}]`. `key` — HID usage code (пробел 44, Return 40, → 79, ← 80, ↓ 81, ↑ 82). В iCloud не синкаются. Писать при закрытом Stage Traxx через `defaults write … -data <hex>`.
- Клавиши на 2026-11-20: пробел = `startStop`, ↑/↓ = `selectionUp`/`selectionDown`, Return = `rewind` (→ = `nextSong` больше нет). Действия «предыдущая песня в очереди» в 4.0.15 нет; в окне назначений «Previous Song/Playlist» = `selectionUp` (курсор в списке), «Next Song in Queue» = `nextSong`, «Rewind to Beginning» = `rewind`.
- Окно назначений в интерфейсе есть: «Remote action assignments», у каждого действия кнопка Learn (ловит клавишу или MIDI). Рядом с AirTurn Setup. AirTurn Support выключен (`AirTurnEnabled = 0`): он пытался взять Ampero как AirTurn и висел в «Connecting».
- Список action raw values (4.0.15) лежит в бинарнике рядом со `startStop`: `startPlayback`, `stopPlayback`, `nextSong`, `rewind`, `jumpToNextRegion`, `cycleRegionForward/Backward`, `toggleQueueAutoplay`, `toggleMuteGroup1..6`, `midiAction1..16` и др. В 4.0.15 пункт «Remote Control» в меню ⋯ отсутствует (он есть в мануале 4.1).

## Футсвич Ampero Control (2026-11-20)

Hotone Ampero Control (EC-4, 4 кнопки) управляет Stage Traxx по **USB** (кабель; порт `Ampero Control`, class-compliant MIDI).

| Кнопка | Шлёт | Stage Traxx |
|---|---|---|
| FS1 | CC 20 = 127, ch 16 | `stopPlayback` + `rewind` — стоп и в начало песни |
| FS2 | CC 21 = 127, ch 16 | `selectionUp` + `triggerSelection` — предыдущая песня |
| FS3 | CC 22 = 127, ch 16 | `startStop` — пауза / старт |
| FS4 | CC 23 = 127, ch 16 | `nextSong` — следующая песня |

- **Stage Traxx:** `tools/stagetraxx_remote.py` (dry-run показывает назначено/нужно; `--apply --quit --launch` пишет). Формат MIDI-триггера снят с Learn: `{"midiCC": {"channel": 16, "controller": 23, "value": 127}}`, канал с 1. Одному CC — несколько записей, по одной на действие. Клавиатурные назначения скрипт не трогает, записи на канале 16 заменяет целиком. Бэкап prefs рядом, `*.bak-remote-*`.
- **Ampero:** банк 00, все кнопки Mode **Single** (сообщение уходит на отпускании; Momentary шлёт и на нажатие, и на отпускание → `startStop` дважды). Output To = USB. Канал 16 — чтобы не пересекаться с launcher (1), GM-800 (2), POD Go (3).
- **Программируется только из приложения Ampero Control** (iOS/Android; iPhone-версия стоит и на Mac в `/Applications`). Приложение на Flutter говорит с пультом по своему BLE-сервису `36D70001-A25B-40FE-99A0-36453A1D8704`, не по Bluetooth-MIDI; по USB настройку не записать (на SysEx identity не отвечает).
- **ГРАБЛЯ Save:** после Save приложение пишет «Connection failed», но банк сохраняется. По логу Mac-версии (`log stream --predicate 'process == "Ampero Control"'`): оба блока банка уходят целиком, через ~2 с пульт сам рвёт Bluetooth (видимо, пишет память), приложение считает это ошибкой. Проверять не по сообщению, а педалями.
- Без программирования банк 00 пустой: педали ничего не шлют.
- Bluetooth-MIDI с Mac тоже работает (Audio MIDI Setup → MIDI Studio → Configure Bluetooth → Connect, порт `Ampero Control Bluetooth`), но на сцене — кабель.
- Вживую на репетиции ещё не проверено; FS1 и FS2 — по два действия на один CC, работают ли оба, проверить нажатием.

## Заметки песен в центральной области (2026-11-17)

`stagetraxx_sync.py` кладёт заметку песни с дашборда под MIDI-теги в поле lyrics — Stage Traxx показывает её в центральной области. Источник — `web/data/dashboard.db` (локальная доска, как у `stage_sheet.py`), чистка как у стейдж-листа (без пустых строк и повторов), запись `NOFOLDER:<sid>` подмешивается. Синк владеет этим текстом: правки делать на доске, ручной текст в Stage Traxx заменится (dry-run предупреждает). Нет базы дашборда — текст песен не трогается. Схемы аккордов и разметка текста — раздел [Схема аккордов](#схема-аккордов-гайд-2026-11-20). Прод-доска (Neon, basic auth) не используется. Первый прогон: заметки у 55 из 62 песен.

## Схема аккордов (гайд, 2026-11-20)

Как вывести аккорды песни в Stage Traxx. Формат согласован с Alex на «Знаешь ли ты»: [страница песни](../songs/maksim-znaesh-li-ty.md#аккорды-в-stage-traxx).

**1. Аккорды.** Если источника нет (табы, MIDI, JamZone `tiles.json`), снимать со стемов по сетке тактов из `mix.json`. Аккорд на каждую долю: хрома гармонических стемов (keys / piano / strings / other, бэки с половинным весом), шаблоны мажорных и минорных трезвучий. Корень брать по басу, а где баса нет — по нижнему регистру пиано. Спорные доли разбирать по составу нот: квинта без терции = C#5, трезвучие на чужом басу = обращение или септаккорд. Потом свернуть такты в последовательности и найти повторы. Тональность — как у плейбека (`pitch_semitones`). Писать, что аккорды авто и на слух не сверены.

**2. Формат** (обычный текст, без скобок):

```
Интро 1–6
A B ×2 | A G#
Барабаны 24–39, блок ×2
Ebm B Db ×2 | B Db
Ebm B Db Bbm
```

- Название части с тактами всегда на своей строке.
- Под ним строки по 4–6 аккордов. Каждая последовательность один раз, повтор как `×N` в строке, последовательности одной части через ` | `. Строк из 2–3 аккордов не делать. Длинную часть делить по тактовой черте.
- Заголовок «Аккорды» не нужен. Квадратных скобок не ставить: `[A]` Stage Traxx читает как ChordPro, рисует аккорд над строкой текста, а всё, что вне скобок (`|`, `×2`), уходит строкой ниже. Каждая строка тогда занимает две.

**3. Куда.** Схему записать заметкой песни на локальной доске (`web/data/dashboard.db`), ключ — папка песни. Доска сохраняет состояние целиком, поэтому писать через её API: `GET /api/state` → поменять `songs[<папка>].notes` → `PUT /api/state` (localhost:5173). Если доска открыта во вкладке, её надо обновить до следующей правки там, иначе старая вкладка затрёт заметку. Ту же заметку печатает `stage_sheet.py`, так что никакой разметки на доске.

**4. Синк.** `tools/stagetraxx_sync.py "<песня>"` → `--apply --quit` (без `--launch`: Stage Traxx после синка не открывать, Alex 2026-11-20). Сверить текст в базе (`song.lyrics`).

**Цвета.** Синк красит сам (`color_chart_note`). Если в заметке есть `×N` или `|`, во всех её строках аккордов аккорды зелёные, `×N` оранжевые, `|` серые. Отдельно стоящий `×N` в строке с текстом тоже оранжевый. В заметках без `×N` и `|` строки из одних аккордов Stage Traxx подсвечивает сам. Под это правило уже попадают I Love It, «Я сошла с ума» и It's Raining Men (покрасятся при своём следующем синке).

**Разметка текста Stage Traxx** (взята из демо-песни внутри приложения): `{c:<цвет>}текст{c}`, цвета blue, gray, green, orange, pink, purple, red, teal, white, yellow; `*жирный*`, `_курсив_`, `+подчёркнутый+`, заголовки `#` / `##` / `###`; строки вида `[00:30.00]` — таймкоды автоскролла.

## Трек All и мьют-группы (2026-11-17)

- **Громкость Drums / Vocals / All (2026-11-20).** Это единственные дорожки, у которых громкость в Stage Traxx не 0 дБ. Стемы сайта идут на громкости оригинального мастера и гуляют от песни к песне на 13 дБ (барабаны −23.8…−10.5 при басе плейбека около −19): после калибровки живой бас тонул под ними. Синк меряет каждый такой файл и ставит громкость дорожки = цель − замер, но не выше 0 дБ (тихий стем остаётся тихим). Цели `PRACTICE_LEVEL`: Drums −17, Vocals −21, All −16. Замеры кэшируются в `~/.cache/cherry-daddies/stagetraxx-levels.json`, dry-run показывает убавку рядом с именем дорожки (`Drums-4.7`). Ручная правка этих фейдеров заменяется следующим синком: менять цель в `PRACTICE_LEVEL`. Обоснование целей: [Опорные точки громкости](level-anchors.md).
- **7 All** — `auto-render/all.wav` (вся песня в ключе группы, без клика/cues), шина 3, `mute = 1` (как Drums/Vocals: на гиге шина 3 = зал).
- Мьют-группы пишутся в `track.muteGroupMask` (бит 0 = группа 1, проверено по экрану 2026-11-18). **Группа 1** = PB Other, PB Bass, Drums, Vocals → All + клик + cues. Click и Cues ни в одной группе: пока группа включена, её треки нельзя размьютить вручную, а с All клик и cues нужны всегда (Alex, 2026-11-18; прежняя группа 1 «только All» их глушила, группа 2 была её дублем и убрана). Группы глобальные (на все песни).
- Библиотека после этого — 7.8 ГБ.

## Грабля: посторонний звук при опущенных фейдерах (2026-11-18)

На «Ты меня не ищи» сам начинал играть дист-синт: звучал и при всех опущенных фейдерах, с разных мест песни при каждом перезапуске, потом затихал. Причина — **Logic Pro, открытый параллельно** (5 дней, проект `~/Downloads/ты меня не ищи.logicx`). Stage Traxx на play шлёт MIDI START, клок и PC, Logic по ним запускает свой проект и играет его прямо в интерфейс, мимо микшера Stage Traxx. GM-800 проверен по SysEx: слоты 27 = NE ISHI BASS и 30 = NE ISHI SOLO правильные, Heads Will Roll в слоте 13 этой песней не вызывается. Правило: на репетиции и концерте с Stage Traxx Logic/MainStage закрыты, либо в Logic выключена внешняя синхронизация (File → Project Settings → Synchronization: внешняя синхронизация и приём MIDI Clock/MMC).
