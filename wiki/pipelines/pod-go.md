# Line 6 POD Go — переключение из Stage Traxx

Гитарный процессор Alex, подключён к Mac по USB (с 2026-11-17). В macOS виден как MIDI-устройство `POD Go` (вход и выход). Отдельного MIDI-разъёма нет, только USB.

## Проверено (2026-11-17)

- Program Change с Mac (`C0 04`, канал 1) переключил POD Go на **02A**. Значит, `PC n` = банк `n//4 + 1`, буква `A–D` = `n % 4`: PC0 = 01A, PC4 = 02A, PC127 = 32D. Bank Select не нужен.
- Канал по умолчанию — **1**. Это конфликт: Stage Traxx шлёт теги на все MIDI-выходы (порт в теге не выбрать), а 57 песен при загрузке шлют `PC<клип>@1` для lyric-launcher. На канале 1 POD Go прыгает на случайный пресет при выборе песни. Решение: на приборе **Global Settings → MIDI/Tempo → MIDI Base Channel = 3** (1 = launcher, 2 = GM-800).

- После перевода прибора на канал 3 (Alex, 2026-11-17): `PC0@1` игнорируется, `CC69 = 2` на канале 3 включил снапшот 3 (значения 0–3 = снапшоты 1–4).
- **Alex снапшотами не пользуется, только пресетами** → в тегах только PC.

## Не проверено

- Провал звука при смене пресета посреди песни.

## Пресеты по песне: `mix.json` → теги Stage Traxx (сделано 2026-11-17)

```json
"podgo": "02A"
```
Вся песня на одном пресете.

```json
"podgo": [
  {"bar": 1,  "preset": "02A"},
  {"bar": 33, "beat": 3, "preset": "03C"}
],
```
Смены по такту/доле музыки, одна запись на строку (как cue и `gm800`).

1. `jamzone_render.py "<song>"` (или `--check`) вписывает в каждую запись `abs_sec` — секунду самого такта в рендере.
2. `stagetraxx_sync.py --apply "<song>"` пишет теги:
   - стартовый пресет: `[midi: PC<n>@3]` + `[midi@00:00.000: PC<n>@3]`;
   - каждая смена: `[midi@<abs_sec − 0.200>: PC<n>@3]` — **за 200 мс до такта** (решение Alex: пресет должен успеть встать к доле). Константа `PODGO_LEAD`, не меньше 00:00;
   - повтор того же пресета выбрасывается.
3. `n = (банк − 1) × 4 + A..D` (`02A` → 4, `32D` → 127). Канал — `--podgo-channel` (по умолчанию 3).
4. Код общий с GM-800: таблица `DEVICES` в `stagetraxx_sync.py`, `MIDI_DEVICES` в `jamzone_render.py`. Тесты: `tools/jamzone/tests/test_podgo.py`.

- **31D = MUTE** (патч Alex для песен без живой гитары).
- `"podgo": "31D"`: Around the World, Destination Calabria, Солнышко, Infinity 2008, No Stress, Ты меня не ищи, Попрошу тебя.
- Солнце: куплеты и вступление 32B, припевы 32D (по тактам).
- Не решено (на доске только синт): Беги от меня, Beverly Hills, Кислотный DJ, Better Off Alone, Mr. Saxobeat, Now You're Gone, S&M.
