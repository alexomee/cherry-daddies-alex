публикуются в существующий R2, `https://releases.agentiqa.com/cherry-dash/`.
На первом запуске опубликованы **37 WAV, 1.406 ГБ**. Доступ по ссылке, без ключей

- Каталог: [`music/guide-catalog.json`](../../music/guide-catalog.json).

- После публикации каталог нужно commit/push в основном репо. Сам музыкальный
  рендер не запускает upload; это отдельный штатный шаг публикации.

## На ноутбуке Тани

Из основного репозитория: `lyric_workflow.py sync`, затем `preview NN`.
Команды выполняет агент. `guide NN` — только получить/проверить выбранный WAV.
Полные команды без Homebrew: [workflow](../../docs/vocalist-workflow.md).

WAV скачивается только для выбранной песни, в игнорируемый кэш `.local/guides/`.
Из partial/sparse-рига получаются только выбранные аудиофайлы и lyric-метаданные.
`preview` строит видео с теми же сценическими строками, полным вокальным миксом,
актуальными click/cues и таймкодом. Готовый JamZone ASS можно смотреть без tiles.
Таня смотрит целиком и подтверждает явно; автоматическое approve запрещено.

## Проверки и ограничения

Все 37 опубликованных WAV проверены полным HTTP-скачиванием: SHA-256, размер,
`Content-Type: audio/wav`. Для **24/24** песен lyric-сетлиста проверены отпечатки
render-клика и общих playback-стемов против текущего рига. Это проверка совместимой
версии аудио, не человеческое подтверждение текстов и не доказательство правильности
каждого ранее сделанного музыкального рендера.

При несовпадении файловых хешей допускается сравнение PCM: 44.1 kHz stereo,
16-bit, тишина ≤4 единиц PCM обнуляется (−78 dBFS). Не выполняются сдвиг,
нормализация или растяжение. Даже сдвиг на один сэмпл меняет отпечаток.
Прецеденты: у «Мелом» отличается заголовок WAV, PCM тот же; у Coldplay
«Adventure of a Lifetime» 44 отсчёта хвоста отличаются максимум на 3 единицы PCM,
музыкальный сигнал совпадает. Новая озвучка cue допустима — для review берётся риг.

Отсутствующий/устаревший guide останавливает процесс с точным именем файла и
способом получить его через Alex. Немой сценический MP4, `pb-other.wav`,
`practice-tanya.mp3` без вокала и dashboard `all.mp3` (это `cue_preview.mp3`)
не подходят вместо чистого guide.
