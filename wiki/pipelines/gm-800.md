# BOSS GM-800 — сцены и лайвсеты

Гитарный синт Alex (ZEN-Core). Тоны (1206 штук, 47 категорий) зашиты в ROM и не стираются. В памяти прибора 150 пользовательских **сцен**. Каждая сцена хранит выбор тонов для 4 партий + ритм-партии, TONE MODIFY и эффекты.

Документы BOSS: [Sound List](https://static.roland.com/assets/media/pdf/GM-800_soundlist_multi01_W.pdf), Reference Manual, Parameter Guide, MIDI Implementation, Using BOSS TONE STUDIO. Все лежат на странице поддержки boss.info → GM-800 → Owner's Manuals.

## Раскладка слотов (решение Alex, 2026-11-17)

| Слоты | Что | Как переключается |
|---|---|---|
| 1 | MUTE: уровни всех партий 0, для песен без синта | PC из Stage Traxx |
| 2–50 | сцены банды | PC из Stage Traxx |
| 51–150 | заводские сцены 1–100, заводская N в слоте 50+N | педаль или вручную |

- Сцены банды лежат ниже 128, значит хватает обычного PC. Bank Select не нужен: прибор стартует в банке 0, а банк запоминается.
- Сцены переключаются по MIDI из Stage Traxx внутри песни. Таймкод пишется тегом в поле lyrics: `[midi@01:34.50: PC…@ch]`. Синтаксис найден в бинарнике Stage Traxx 4 («Timed MIDI command»). Старая схема «PC# = номер сцены» для `web/stage.html` устарела.
- **Проверено 2026-11-17** (тест на Солнышке, монитор на виртуальном порту + экран GM-800):
  - Stage Traxx шлёт сырое число из тега, а GM-800 показывает сцену на 1 больше. Значит, **тег = `PC<сцена−1>@2`**: MUTE = `PC0@2`, сцена 7 = `PC6@2`.
  - Таймкод-теги срабатывают по позиции песни с точностью ±3 мс (~10 мс после START). После паузы и продолжения срабатывают только теги, которые ещё впереди.
  - `[midi: …]` срабатывает только при загрузке песни. Если повторить песню с начала без перезагрузки, тег загрузки не повторится. Поэтому стартовую сцену надо дублировать тегом `[midi@00:00.00: …]`.
  - Синтаксис `PC1.2@3` = CC0 0 + CC32 2 + PC 1, то есть `.N` — это Bank LSB (MSB всегда 0).
  - PC launcher'а на канале 1 (`[midi: PC12@1]`) GM-800 с Scene Rx Ch2 игнорирует.
- Ещё не проверено: обрыв звука при смене сцены во время игры.
- Нужно настроить на приборе:
  - **PC Out = OFF**, иначе GM-800 вернёт PC в Stage Traxx, а тот умеет искать песню по входящему MIDI;
  - отдельный Scene Rx Channel;
  - Scene Extent 1–50, чтобы педаль не уходила в заводские.
- lyric-launcher реагирует на PC на любом канале, фильтра нет.

## CTL-кнопки и MIDI (по Parameter Guide и MIDI Implementation v1.03, 2026-11-17)

- CONTROL FUNCTION (◀ ▶ CTL1–CTL6 GK SW1–2) работает **только от физических кнопок**: принять «нажатие CTL1» по MIDI прибор не умеет.
- Внешнее управление — через **ASSIGN** сцены (16 штук): SOURCE = `CC#1–31` или `CC#64–95`, TARGET например `PART1 TONE SELECT → Part Sw` / `Part Level`; значение = MIN…MAX по ACT LOW…ACT HIGH. CC принимаются на **Scene Rx Channel** (у нас 2). CC 71–79 заняты прямыми ручками тона (attack, cutoff, decay, vibrato…), их не брать.
- В tsl: `ControlFunctionForSw(n)`, n = 1 ◀, 2 ▶, 3 CTL1, 4 CTL2, 5–8 CTL3–6, 9–10 GK SW1–2. Байт 0 = FUNCTION (0 OFF, 1 SCENE−1, 2 SCENE+1, 3 TUNER, 4 TAP, 5 PART ON/OFF, 6 HOLD, 7 PITCH BEND, 8 MOD, 9 OCT, …), байт 1 = MODE (0 TOGGLE, 1 MOMENT), дальше по 6 байт на партию. `ToneSelect(p)`: MSB, LSB, PC−1, ?, **Part Sw**.
- «Ты меня не ищи» (слот 27 NE ISHI BASS): CTL1 = PART ON/OFF, TOGGLE, на партии 1 (670 New Reso Bs 2, в сцене выключена) и 2 (644 Hammer Bass Atk, включена).

### `gm800_cc` в mix.json (сделано 2026-11-17)

```json
"gm800_cc": [
  {"bar": 1,  "cc": 80, "value": 0},
  {"bar": 17, "cc": 80, "value": 127}
],
```
Первое событие каждого CC — стартовое состояние: уходит при загрузке и на 00:00, после PC сцены. Остальные — за 0.5 с до такта (`GM_CC_LEAD` = `SWITCH_LEAD`; до 2026-11-18 было 200 мс), на канале GM-800 (2). CC только 1–31 / 64–95, не 71–79. Рендер вписывает `abs_sec`, тесты в `test_podgo.py`.

**«Ты меня не ищи»:** CC80 = 0 на старте, 127 на такте 17 «bass in» (0:31.198) → вместо CTL1: Hammer Bass выкл, Reso Bass вкл. В слоте 027 (NE ISHI BASS): ASSIGN 1 — SW ON, TARGET P-1 PART SW, MIN OFF, MAX ON, SOURCE CC#80, **MOMENT**, ACT 0–127; ASSIGN 2 — TARGET P-2 PART SW, MIN ON, MAX OFF (перевёрнутый диапазон работает), остальное так же. **Сделано и проверено 2026-11-17** по SysEx: записано прямо в память слота, после перезагрузки сцены CC80 = 127 → партия 1 вкл / 2 выкл, 0 → наоборот; Alex подтвердил на слух. Сохранность после выключения питания не проверялась — снять свежий экспорт прибора в `gear/gm-800/backups/`. Лайвсет `livesets/2026-11-17-v3.tsl` этих ASSIGN не содержит.

Грабли: правки в BOSS TONE STUDIO до WRITE живут только в загруженной сцене, а PC той же сцены (Stage Traxx при загрузке песни, тест) перезагружает её из памяти и стирает их. Экран BTS при этом может показывать уже потерянные правки. TOGGLE для CC-источника не годится: каждый CC переворачивает состояние; нужен MOMENT.

### SysEx GM-800 (MIDI Implementation v1.03)

- **Уровень партии по SysEx (2026-11-19):** ToneSelect p, смещение `06` = PART LEVEL (0–127), `04` = PART SW, `08` = MUTE SW. DT1 в память слота применяется сразу (после PC сцена грузится с новым значением); сохранность после выключения питания не проверена. Слот 27 NE ISHI BASS: партия 2 `127 → 90`, партия 1 `98 → 88` — выровнено с басом сцены 7 ([level-anchors](level-anchors.md)). ⚠️ `gear/gm-800/livesets/2026-11-17-v3.tsl` этих значений не содержит.
- **Игра от MIDI-нот (2026-11-19, MIDI Implementation v1.50):** SystemMidi `00 00 06 00`: +00 Scene Rx Ch, +01…+04 Part 1–4 Rx Ch (у нас Ch 11–14), +05 Part R Rx Ch (Ch 10), +08 NOTE SOURCE (0 GK IN, 1 MIDI, 2 USB, 3 CUSTOM), +09… источник по партиям. При NOTE SOURCE = USB прибор играет ноты с USB-MIDI на каналах партий; датчик при этом молчит. Звук идёт в Mac по USB-аудио 1/2. Так `tools/live_levels.py gm800` меряет громкость сцен — [level-anchors](level-anchors.md#живая-сторона-замер-без-игры-руками-2026-11-19).

- Model ID `00 00 00 00 26`, device ID `10`. RQ1 = `F0 41 10 00 00 00 00 26 11 <addr4> <size4> <sum> F7`, DT1 = `… 26 12 <addr4> <data…> <sum> F7`, sum = (128 − сумма адреса и данных mod 128) mod 128. Ответы идут с порта `GM-800`; BTS, если открыт, сыплет свой трафик туда же.
- Адреса: SystemMidi `00 00 06 00` (байт 0 = Scene Rx Channel − 1; у нас 01 = Ch2), загруженная сцена `10 00 00 00`, слот N в памяти = `40 00 00 00` + (N−1)·`00 10 00 00` в 7-битной арифметике (слот 27 = `43 20 00 00`, слот 51 = `46 20 00 00`). Внутри сцены: Common `+00 00 00` (имя с байта 0), Assign n `+01 0(n−1) 00` (29 байт), ToneSelect p `+02 0(p−1) 00` (байт 4 = Part Sw).
- Assign: SW, TARGET (4 ниббла), MIN и MAX (по 4 ниббла, значение + 0x8000), SOURCE, MODE (0 TOGGLE, 1 MOMENT), ACT LOW/HIGH, RISE/FALL, MIDI-поля для вывода. TARGET: P-1 PART SW = 5, P-2 PART SW = 14 (по 9 параметров на партию: PART SW, TONE NUM, LEVEL, PAN, C/D SEND, REV SEND, OUTPUT, MUTE SW, PEDAL POS). SOURCE: 0 DOWN, 1 UP, 2–7 CTL1–6, 8–9 EXP1–2, 10–11 GK SW1–2, 12 GK VOL, 13–43 CC#1–31, 44–75 CC#64–95 (CC#80 = 60).
- Инструмент: `tools/midiq.swift` (отправить сообщения и напечатать ответы порта).

## Сцены по песне: `mix.json` → теги Stage Traxx

В `mix.json` песни добавляется ключ `"gm800"`:

```json
"gm800": 1
```
Вся песня на одной сцене. 1 = MUTE, для песен, где Alex играет обычную гитару.

```json
"gm800": [
  {"bar": 1,  "scene": 7},
  {"bar": 17, "scene": 8},
  {"bar": 25, "beat": 3, "scene": 9}
],
```
Смены сцены задаются так же, как cue: такт/доля по сетке музыки, одна запись на строку.

1. `jamzone_render.py "<song>"` (полный рендер или `--check` без аудио) вписывает в каждую запись `abs_sec` — секунду в рендере. Считает той же функцией, что cue (`cue_event_time`: каунт-ин, смены темпа, `click: follow`). Проверено на копии Солнышка: такт 17 → 31.304 с, совпадает с cue «alex in».
2. `stagetraxx_sync.py --apply "<song>"` пишет теги в поле lyrics:
   - стартовая сцена: `[midi: PC<s−1>@2]` и `[midi@00:00.000: PC<s−1>@2]`;
   - каждая смена: `[midi@MM:SS.mmm: PC<s−1>@2]`;
   - повторный выбор той же сцены выбрасывается.
3. Если `abs_sec` нет или запись битая, dry-run показывает `! GM-800 tags skipped`, а `--apply` отказывается писать.
4. Канал задаётся `--gm-channel` (по умолчанию 2). Если ключа `gm800` нет, тегов GM-800 у песни нет совсем.
5. Тесты: `tools/jamzone/tests/test_gm800.py`.

## Инструмент `tools/gm800_tsl.py`

`.tsl` — это JSON: `{name, formatRev, device:"GM-800", data:[[{memo, paramSet}]]}`. Позиция в списке = слот. Имя сцены — байты 3–18 `User_Scene%Common`.

```bash
tools/gm800_tsl.py ls   gear/gm-800/backups/2026-11-17-device.tsl --factory gear/gm-800/backups/2026-06-16-factory.tsl
tools/gm800_tsl.py diff A.tsl B.tsl
tools/gm800_tsl.py build gear/gm-800/plan-2026-11-17.json   # → gear/gm-800/livesets/<name>.tsl
```

План — JSON: источники (`dev`/`jun`/`fac`) и `slot ← source:slots`, опционально `rename`. Пустые слоты заполняются INIT.

## Процесс

1. **Бэкап.** Librarian → Import (с прибора) → Export → EXPORT TO FILE → `gear/gm-800/backups/<дата>-device.tsl`. Делать после каждой правки на приборе.
2. **План.** Правка `gear/gm-800/plan-*.json`, затем `build`.
3. **Запись.** Librarian → Import → IMPORT FROM FILE (собранный `.tsl`) → Export → EXPORT TO GM-800.
4. **Сверка.** Снова импорт с прибора → экспорт в файл → `diff` с собранным: должно быть 150/150.

## Лайвсет 2026-11-17 v2 (история)

**Сцены вида `<ПЕСНЯ>-` — это заглушки.** Это копии INIT с SCENE LEVEL = 0 (байт 19 в `Common`), то есть по сути мьют. В v2 они все слиты в слот 1 MUTE. Так у 18 песен: Солнце, Такая любовь, Ту-лу-ла, Blinding Lights, Whenever, Freed, Про красивую жизнь, Я устал, Медляк, Медведица, Pretty Fly, Кукла колдуна, Мама Люба, Мелом, Я сошла с ума, Ghostbusters, Adventure, Uptown.

- 1 — MUTE.
- 2–13 — синт-сцены Music Hall.
- 14–16 — новые песни 12.12.
- 17–28 — июньская программа.
- 29–50 — свободны.
- 51–150 — заводские.

**Как схлопнулись дубли:**
- Дубли по секциям (Saxobeat SAX/SYNTH ×5 → 2, Infinity ×8 → 2, Мало тебя ×5 → 2) были побайтными копиями. Они нужны были, чтобы педалью шагать по секциям.
- Три «SOLNbISHKO LEAD» отличались только SCENE LEVEL: 110 / 111 / 81. В v2 оставлен вариант 110. Тихий 81 (последний LEAD в песне) лежит в бэкапе прибора, слот 20.
- Одинаковый звук у разных песен: BEGI = BEVERLY (OB Bright Str + Voyager Pad + Aurora Pad). Lead-стек из 4 тонов общий у Солнышка, Мало тебя SOLO, I Love It и We Found Love. Бас Солнышка ≈ NO STRESS BASS. Сцены всё равно оставлены отдельные, по одной на песню.

Первая сборка (`2026-11-17-target.tsl`) — история: в ней заглушки ещё лежали отдельными сценами.

## Подбор тонов

- Сначала мерить огибающую (атака/спад по нотам), потом гармоники. По одному спектру мягкий lead от молоточка не отличить: «Ты меня не ищи» сначала ошибочно определили как square lead, а это mallet.
- Кандидаты для «Ты меня не ищи»: 493 Xylophone 1, 1069 Synth Mallet, 1078/1079 Seq Sqr 1, 1072 Sine Mallet, 355 Atk Sine Pluck.
- Заводские сцены с этими тонами (декод `ToneSelect(n)` = MSB/LSB/PC−1 по Sound List, 2026-11-17): **34 SYNTH PLEDGE** — 350 Saw Seq + 355 Atk Sine Pluck + 1078 Seq Sqr 1 + 1077 Seq 3; **55 GALAXIAL HARP** — 1069 Synth Mallet + 1088 Uni-G + 143 Harp 2. Ещё молоточки: 22 JAZZ VIBE TRIO (62 Warm Vibraphone + бас + райд), 44 WUNDERLAND (476 Glockenspiel), 59 TROPICAL HEAVEN (Steel Drums + Vibraphone). Xylophone 1 (493) ни в одной заводской сцене нет. В раскладке 51–150 заводская N лежит в слоте 50+N.
- **«Ты меня не ищи», lead — разбор референса** (`~/Downloads/ты меня не ищи lead.mp3`, 2026-11-17). Mallet-кандидаты отклонены: «объёмные», а без эффектов «детские». Что в референсе: квадрат/пульс (3-я гармоника −8.5 dB, 2-я −14); **слой на октаву ниже** ~−15 dB (пики на 0.5×/1.5×/2.5× f0); огибающая — атака ~10 мс, −6 dB к ~90 мс, дальше держится до следующей восьмой; **крутой срез верха** (2–5 кГц −35 dB, выше 5 кГц почти ничего), энергия в 0.5–2 кГц; почти сухо (L/R corr 0.85). Ноты E5–C5–A4. Рецепт: квадрат (217 Oct Square Lead / 950 Octa Square — октава уже внутри; или 1079 Seq Sqr 1 Atk + вторая партия Oct −1 на ~40% уровня) → TONE MODIFY Attack −64, Decay −20…−30, Release короткий, Cutoff −20…−30, Resonance +10…+20 → MFX 44 Gt Amp Sim или 38 T-Scream / 43 W Saturator (умеренно) для «шершавости»; Cho/Dly и Reverb send 0. Ещё кандидаты: 239 Buzz Square Ld, 893 Sqr Buzz Lead, 354 Lo-Fi Comp Pluck. Собирать с INIT-сцены, не с заводской.
- Кандидаты для «Попрошу тебя»: [страница песни](../songs/virus-poproshu-tebya.md).
